# **App Name**: Code Dispenser

## Core Features:

- Code Generation: Generates a random 4-digit code from a given set of 4-digit numbers.
- Code Display: Displays the generated code in a rectangle with a neon red border.
- UI: Includes a thin red vertical bar on the left edge and a wider black vertical bar on the right edge as purely decorative elements.

## Style Guidelines:

- Primary color: A deep navy blue (#243A73) reminiscent of corporate environments, lending seriousness to the codes presented.
- Background color: A desaturated sky blue (#D4E0F0), suggesting a corporate atmosphere but maintaining subtlety.
- Accent color: Neon red (#FF312E) used for code display borders and small accents, catching attention and resonating with urgency.
- Body and headline font: 'Inter' - sans-serif, known for clarity, which ensures the codes displayed are easily readable at a glance. Especially suited for UI
- The interface features a background image of people walking in a large company, viewed from above, to give context and depth. Code display rectangle in the center, ensuring immediate visibility. Side bars included, red on the left, black on the right.
